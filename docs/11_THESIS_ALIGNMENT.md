# Thesis Alignment

The broader thesis documents describe high-frequency trend classification, adaptive labeling, financial evaluation, and XAI. This repository is a narrower regression benchmark used to establish whether the data and a simple CNN-LSTM contain measurable one-hour-ahead predictive signal.

It does not replace the broader thesis scope unless a separate decision is recorded.

Claims from this repository are limited to:

- BTCUSDT only,
- future-return regression,
- one-hour horizon,
- the documented period and split,
- the documented feature sets and models.

Do not present this repository as an exact replication of ACLMC or another paper. It is a controlled benchmark and diagnostic track.
